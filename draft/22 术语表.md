## 术语表

| 术语           | 定义                                                         |
| -------------- | ------------------------------------------------------------ |
| 128b/130b 编码 | 这种编码与 的含义不同。发送端以块（Block）为单位传输信息，每个块由连续的 16 个原始字节组成，前面带有一个 2 位的同步字段（Sync field），用于指示该块应被视为数据块（Data Block）还是有序集块（Ordered Set Block）。该方案随 Gen3 引入，主要目的是在不加倍时钟频率的情况下使链路带宽翻倍。它提供了更好的带宽利用率，但牺牲了 为接收端提供的一些优势。 |
| 8b/10b 编码    | 多年前开发的编码方案，如今仍广泛应用于多种串行传输中。该方案旨在帮助接收器从输入信号中恢复时钟和数据，但同时也使接收器的可用带宽降低了 。此方案用于早期版本的 PCIe：Gen1 和 Gen2。 |
| ACK/NAK 协议   | 确认/否定确认机制，数据链路层通过该机制报告 TLP 在传输过程中是否出现错误。若出现错误，则向发送方返回 NAK，请求重发失败的 TLP；若未出现错误，则返回 ACK，表示一个或多个 TLP 已安全到达。 |
| ACPI           | 高级配置与电源接口。定义了系统和设备的多种电源状态。         |
| ACS            | 访问控制服务。                                               |



| 术语     | 定义                                                         |
| -------- | ------------------------------------------------------------ |
| ARI      | 备用路由 ID 解释；可选功能，允许端点拥有超过常规允许的 8 个功能。 |
| ASPM     | 主动状态电源管理：启用后，允许硬件将链路电源状态从 L0 更改为 L0s 或 L1，或同时更改两者。 |
| 原子操作 | 原子操作；2.1规范修订版新增的三个请求。这些请求执行多个操作，确保在目标设备内不间断地完成。 |
| 带宽管理 | 硬件发起的链路速度或宽度变更，旨在实现节能或提升可靠性。     |
| BAR      | 基地址寄存器。由功能设备用于指示其本地内存和输入输出空间的类型及大小。 |
| 信标     | 设备主电源关闭后，用于向系统发送事件信号的低频带内信号，表明需要恢复供电。该信号可在链路处于 L2 状态时通过链路传输。 |
| BER      | 误码率（Bit Error Rate/Bit Error Ratio）；基于特定时间段内检测到的传输比特错误数量，衡量信号完整性的指标。 |
| 比特锁定 | 在接收端获取发射端精确时钟频率的过程。该过程在时钟数据恢复（CDR）逻辑中完成，是链路训练的首要步骤之一。 |
| 块       | 由 Gen3 发送器发送的 130 位单元，由 2 位同步字段后跟一组 16 字节组成。 |



| 术语       | 定义                                                         |
| ---------- | ------------------------------------------------------------ |
| 块锁定     | 在使用 128b/130b 编码时，在接收端找到块边界以识别传入的块。该过程包含三个阶段。首先，在传入的数据流中搜索 EIEOS（电气空闲退出有序集），并调整内部块边界以与之匹配。接着，搜索 SDS（启动数据流）有序集。此后，接收器便锁定在块边界上。 |
| 桥接       | 作为两条总线之间接口的功能。交换机和根复合体将在其端口上实现桥接，以支持数据包路由，同时桥接也可用于连接不同协议，例如 PCIe 与 PCI 之间的连接。 |
| 字节条带化 | 将输出的字节流分散到所有可用通道上。发送字节时，所有可用通道都会被使用。 |
| CC         | 已消耗信用量：发送端在计算流量控制时已使用的信用数量。       |
| CDR        | 时钟与数据恢复逻辑用于从输入比特流中恢复发送器时钟，然后对比特进行采样以识别模式。对于 8b/10b 编码，在 COM、FTS 和 EIEOS 符号中发现的该模式使逻辑能够获取符号锁定。对于 128b/130b 编码，则通过经历锁定的三个阶段，使用 EIEOS 序列来获取块锁定。 |
| 字符       | 用于描述链路邻居之间通信的 8 位值的术语。对于 Gen1 和 Gen2，这些值由普通数据字节（标记为 D 字符）和特殊控制值（标记为 K 字符）混合组成。对于 Gen3，由于不再使用 8b/10b 编码，因此没有控制字符。在这种情况下，所有字符均以数据字节形式呈现。 |



| 术语       | 定义                                                         |
| ---------- | ------------------------------------------------------------ |
| CL         | 信用额度：从发送方视角可见的流量控制信用。用于验证是否有足够的信用额度发送 TLP（事务层数据包）。 |
| 控制字符   | 这些是 8b/10b 编码中使用的特殊字符（标记为"K"字符），用于链路训练和有序集。在 Gen3 中不使用这些字符，因为该代际不对字符进行区分。 |
| 可纠正错误 | 由硬件自动纠正且无需软件关注的错误。                         |
| CR         | 所需信用额度——即信用额度（CC）与部分事务层数据包（PTLP）之和。 |
| CRC        | 循环冗余校验码；附加到 TLP 和 DLLP 中，用于验证无错误传输。其名称含义为：模式具有循环特性且属于冗余信息（不添加任何额外数据）。此类校验码所含信息不足以实现自动纠错，但能提供可靠的错误检测功能。 |
| 直通模式   | 交换机允许 TLP 通过的一种机制：将 TLP 从入端口转发至出端口，无需先存储以检查错误。此机制存在风险，因为 TLP 可能在部分数据已转发至出端口后才被发现存在错误。此时，数据链路层会将数据包末尾的 LCRC 值修改为与正确值相反的值，同时物理层会将其修改为 8b/10b 编码的 End Bad (EDB)帧定界符或 128b/130b 编码的 EDB 令牌。这种组合告知接收端该数据包已被作废，应直接丢弃且无需发送 ACK/NAK 响应。 |
| 数据字符   | 表示普通数据并与 中的控制字符区分的字符（标记为“D”字符）。对于 Gen3，字符之间没有区分。 |



| 术语            | 定义                                                         |
| --------------- | ------------------------------------------------------------ |
| 数据流          | Gen3 操作中的数据块流动。数据流通过 SDS（数据流起始有序集）进入，并以 EDS（数据流结束令牌）退出。在数据流期间，仅允许数据块或 SOS 出现。当需要任何其他有序集时，必须退出数据流，并仅在更多数据块准备发送时重新进入。启动数据流等同于进入 L0 链路状态，因为有序集仅在处于其他 LTSSM 状态（如 Recovery）时发送。 |
| 去加重          | 降低流中重复比特发射器电压的过程。其效果是削弱信号中已知会在传输介质中引起问题的低频分量，从而改善接收端的信号完整性。 |
| 摘要            | ECRC（端到端循环冗余校验）值的另一种名称，该值在事务层创建 TLP 时可选择附加到 TLP 末尾。 |
| DLCMSM          | 数据链路控制与管理状态机；负责管理链路层训练过程（主要是流量控制初始化）。 |
| DLLP            | 数据链路层数据包。这些数据包在数据链路层生成，并转发至物理层，但事务层无法感知。 |
| DPA             | 动态电源分配；2.1 规范修订版中新增的一组配置寄存器，在 D0 设备电源状态下定义了 32 个电源子状态，使软件更容易控制设备电源选项。 |
| DSP（下游端口） | 面向下游的端口，例如根端口或交换机的下游端口。这种区分在 LTSSM 中具有重要意义，因为端口在某些状态下具有指定的角色。 |



| 术语       | 定义                                                         |
| ---------- | ------------------------------------------------------------ |
| ECRC       | 端到端 CRC 值，在事务层创建 TLP 时可选附加。该值使接收方能够验证数据包从源端到目的端的可靠传输，无论传输过程中跨越了多少条链路。 |
| 出口端口   | 具有出站流量的端口。                                         |
| 弹性缓冲器 | 作为 CDR 逻辑的一部分，该缓冲器使接收器能够补偿发送器与接收器时钟之间的差异。 |
| EMI        | 电磁干扰：系统发出的电噪声。对于 PCIe，采用扩频时钟（SSC）和加扰技术来应对该干扰。 |
| 端点       | 位于 PCI 倒置树结构底部的 PCIe 功能。                        |
| 枚举       | 系统发现过程，软件通过读取所有预期的配置位置，以了解哪些 PCI 可配置功能可见并因此存在于系统中。 |
| 均衡       | 通过调整发送端（Tx）和接收端（Rx）的值，以补偿传输介质中实际或预期的信号失真的过程。对于 Gen1 和 Gen2，这表现为发送端去加重（Tx De-emphasis）。对于 Gen3，引入了主动评估流程来测试信号环境并相应调整发送端设置，同时提到了可选的接收端均衡（Rx equalization）。 |
| 流量控制   | 发送端为避免因接收端缓冲区空间不足而导致数据包被拒绝的机制。接收端会定期发送关于可用缓冲区空间的更新信息，发送端在尝试发送数据包前会确认是否有足够的空间可用。 |
| FLR        | 函数级重置                                                   |



| 术语             | 定义                                                         |
| ---------------- | ------------------------------------------------------------ |
| 帧定界符         | 在 8b/10b 编码中用于指示 TLP 或 DLLP 边界的“起始”和“结束”控制字符。 |
| Gen1             | 第 1 代，指设计符合 PCIe 规范 1.x 版本的方案。               |
| Gen1、Gen2、Gen3 | PCIe 规范版本的缩写。Gen1 对应 1.x 版，Gen2 对应 2.x 版，Gen3 对应 3.0 版。 |
| Gen2             | 第二代，指设计符合 PCIe 规范 2.x 版本的方案。                |
| Gen3             | 第三代，指设计符合 PCIe 规范 3.x 版本的方案。                |
| IDO              | 基于 ID 的排序；启用后，允许来自不同请求者的 TLP 相互之间乱序转发，旨在降低延迟并提升性能。 |
| 隐式路由         | 无需参考地址或 ID 即可理解其路由的 TLP。只有消息请求可以选择使用此类路由。 |
| 入端口           | 具有传入流量的端口。                                         |
| ISI              | 符号间干扰；由之前紧邻的比特位对当前比特时间造成的影响。     |
| 通道             | 两个差分对，用于在两个端口之间实现一个比特的发送和接收路径。一条链路可以仅包含一个通道，也可以包含多达32个通道。 |
| 通道间偏移       | 不同通道上比特到达时间的差异。接收器需要检测此差异并在内部进行校正。 |
| 传统端点         | 一种端点，它向前兼容以下三种传统特性中的任意一种：支持 IO 事务、支持仅本地 32 位可预取内存空间，或支持锁定事务。 |



| 术语         | 定义                                                         |
| ------------ | ------------------------------------------------------------ |
| LFSR         | 线性反馈移位寄存器；生成用于实现加扰的伪随机模式。           |
| 链接         | 由一条或多条通道组成的两个端口之间的接口。                   |
| LTR          | 延迟容忍度报告；一种允许设备在发送请求时向系统报告其需要多快获得服务的机制。较长的延迟可为系统提供更多电源管理选项。 |
| LTSSM        | 链路训练与状态状态机；管理物理层的训练过程。                 |
| 非发布请求   | 期望收到完成响应的请求。例如，任何读取请求都属于非发布请求。 |
| 不可预取内存 | 读取时会产生副作用的存储器。例如，读取后自动清零的状态寄存器。此类数据不适合预取，因为如果请求者从未请求该数据且数据被丢弃，系统将永久丢失该信息。这对 PCI 桥接器而言是重要区分点——它们必须猜测读取时的数据大小。若能确定在内存空间中进行推测性预读是安全的，桥接器可猜测更大的数据量以实现更高效率。对于 PCIe 而言，这种区分意义已大幅降低（因为传输的确切字节数已包含在 TLP 中），但保留该特性可确保向后兼容性。 |
| 无效数据包   | 当发送端发现某数据包存在错误且本不应被发送时，该数据包可被"无效化"，即接收端应将其丢弃并视作从未接收过该数据包。此问题在使用交换机的"直通转发"操作时可能出现。 |



| 术语        | 定义                                                         |
| ----------- | ------------------------------------------------------------ |
| OBFF        | 优化的缓冲区刷新与填充；一种允许系统告知设备最佳流量发起时机的机制。若设备在最佳时段发送请求而非其他时段，系统电源管理将得到改善。 |
| 有序集      | 作为物理层通信用于通道管理的符号组。这些符号组通常仅包含用于 8b/10b 编码的控制字符。它们在发送端的物理层生成，并在接收端的物理层被消耗，完全不对其他层可见。 |
| PCI         | 外围组件接口。旨在取代 PC 中使用的早期总线设计，如 ISA。     |
| PCI-X       | PCI 扩展版。旨在修正 PCI 的缺陷并实现更高速度。              |
| PME         | 电源管理事件；设备发出的信号，表示需要与电源相关的服务。     |
| 中毒 TLP    | 创建时已知数据负载存在错误的数据包。发送包含错误数据的数据包有助于诊断问题并确定解决方案。 |
| 极性反转    | 允许接收器的信号极性反向连接，以支持简化电路板布局的情况。接收器需检测此状态，并在链路训练期间内部反转信号以进行纠正。 |
| 端口        | PCIe 链路的输入/输出接口。                                   |
| Posted 请求 | 无需返回完成包的请求数据包。规范中仅定义了两种此类请求：内存写入和消息。 |



| 术语       | 定义                                                         |
| ---------- | ------------------------------------------------------------ |
| 可预取内存 | 可预取内存是指读取时不会产生副作用的内存。这一特性使其可以安全地进行预取操作，因为即使数据被中间缓冲区丢弃，后续需要时仍可重新读取。对于 PCI 桥接器而言，这一区分至关重要——桥接器在读取时需猜测数据大小。可预取空间允许推测性读取更多数据，从而提升效率。对于 PCIe 而言，这种区分已不再重要（因为传输的确切字节数已包含在 TLP 中），但保留该特性可确保向后兼容性。 |
| PTLP       | 待处理 TLP - 发送当前 TLP 所需的流控信用额度。               |
| 服务质量   | 服务质量；PCIe 拓扑结构为不同数据包分配不同优先级的能力。这可能仅意味着在仲裁点优先处理某些数据包，但在更复杂的系统中，它能够为数据包提供带宽和延迟保障。 |
| 请求者 ID  | 请求者进行事务的配置地址，即对应的 BDF（总线、设备和功能编号）。完成者将使用该地址作为返回地址，用于生成相应的完成数据包。 |
| 根复合体   | 作为系统中 CPU 核心与 PCIe 拓扑结构之间接口的组件。它可由一个或多个芯片组成，结构可简可繁。从 PCIe 的角度来看，它充当了 PCI 向后兼容性所要求的倒树结构的根节点。 |
| 游程长度   | 一行中连续出现的1或0的数量。对于 编码，游程长度限制为5位。对于 ，没有明确的限制，但其使用的改进型加扰方案旨在弥补这一不足。 |



| 术语     | 定义                                                         |
| -------- | ------------------------------------------------------------ |
| 加扰     | 对输出比特流进行随机化的过程，旨在避免链路上出现重复模式，从而降低电磁干扰（EMI）。在 Gen1 和 Gen2 中可关闭加扰功能，以允许在链路上指定特定模式；但在 Gen3 中无法关闭，因为在该速率下加扰还承担其他功能，且链路若缺少加扰将无法可靠工作。 |
| SOS      | 跳过有序集——用于补偿发送端（Tx）与接收端（Rx）之间微小的频率差异。 |
| SSC      | 扩频时钟。这是一种通过允许时钟频率在允许范围内来回变化来降低系统电磁干扰（EMI）的方法。该方法将发射能量分散到更宽的频率范围内，从而避免过多 EMI 能量集中在某一特定频率的问题。 |
| 粘滞位   | 其值在复位后仍能保持的状态位。此特性有助于在链路下游功能检测到错误且该链路无法正常运行时，维持状态信息。必须复位故障链路才能访问下游功能，而寄存器中的错误状态信息必须在该复位过程中保持有效，以便软件能够读取。 |
| 交换机   | 包含多个下游端口和一个上游端口的设备，能够在各端口之间路由流量。 |
| 符号     | 通过链路发送的编码单元。对于 8b/10b 编码，这些是编码后产生的 10 位值；而对于 ，它们则是 8 位值。 |
| 符号锁定 | 在使用 8b/10b 编码时，在接收端找到符号边界，以便识别传入的符号，从而识别数据包的内容。 |
| 符号时间 | 在 Link 上发送一个符号所需的时间，Gen1 为 4 纳秒，Gen2 为 2 纳秒，Gen3 为 1 纳秒。 |



| 术语         | 定义                                                         |
| ------------ | ------------------------------------------------------------ |
| TLP          | 事务层数据包。这些数据包在事务层中创建，并通过其他层传递。   |
| 令牌         | 在 Gen3 速度下运行的数据流中，标识所传递信息类型的标识符。   |
| TPH          | TLP 处理提示；这些提示帮助系统路由代理做出选择，以改善延迟和缓解流量拥塞。 |
| UI           | 单位间隔；在链路上发送一个比特所需的时间——Gen1 为 0.4 纳秒，Gen2 为 0.2 纳秒，Gen3 为 0.125 纳秒 |
| 不可纠正错误 | 硬件无法纠正的错误，通常需要软件介入才能解决。这些错误分为致命错误——会导致链路后续操作不可靠，以及非致命错误——尽管检测到问题，但不会影响链路操作。 |
| USP          | 上游端口，指面向上游的端口，例如端点或交换机的上游端口。这一区分在 LTSSM 中具有重要意义，因为在配置和恢复过程中，端口被分配了特定角色。 |

| 术语  | 定义                                                         |
| ----- | ------------------------------------------------------------ |
| 变量  | 在硬件层之间使用多个标志来通信事件和状态。这些标志特定于硬件中的状态转换，通常对软件不可见。例如： - LinkUp - 从物理层向数据链路层发出的指示，表示训练已完成且物理层现已正常运行。 - idle_to_rlock_transitioned - 该计数器跟踪 LTSSM 从 Configuration.Idle 状态转换到 Recovery.RcvrLock 状态的次数。每当识别 TS2 以离开 Configuration 的过程失败时，LTSSM 会转换到 Recovery 状态以采取适当措施。如果经过 256 次 Recovery 循环（计数器达到 FFh）后仍无法正常工作，则返回 Detect 状态重新开始。这可能表明某些通道无法正常工作。 |
| WAKE# | 用于向系统发出信号以恢复供电的边带引脚。在注重节能的系统中，它替代了 Beacon 信号。 |
